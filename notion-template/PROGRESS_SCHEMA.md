# Схема прогресса в Notion

Создай одну базу данных «Мои уроки» с 18 записями. Все страницы идут по одному порядку из STAGES.csv. Это единственное место, где Codex хранит статус и доказательства курса. Ученик работает с уроком и его чек-листом; базу статусов Codex обновляет сам.

## Свойства базы

| Поле | Тип Notion | Назначение |
|---|---|---|
| Название | Title | Название этапа |
| ID | Text | Стабильный ID M1.S1–M6.S3 |
| Порядок | Number | Порядок от 1 до 18 |
| Модуль | Select | Один из шести модулей |
| Статус | Select | Текущее состояние этапа; варианты перечислены ниже |
| Доказательство | Text | Короткое проверяемое подтверждение и путь к артефакту, если он есть |
| Заметка наставника | Text | Короткая проверка критерия |
| Следующее действие | Text | Одно ближайшее действие, пока этап не пройден |
| Источник | URL | Локальная программа в Git, если URL уже известен |

## Статусы

- Не начато
- В процессе
- Готово к проверке
- Нужна доработка
- Пройдено
- Нужно решение

Ученик не редактирует статусы и доказательства базы. После сообщения «Готово, проверь» Codex проверяет файлы, наблюдения и объяснение ученика. Не отмечай этап пройденным только потому, что код запускается; запиши доказательство по каждому обязательному критерию и короткое объяснение ученика.

## Как ученик видит прогресс

- На главной странице есть только ссылка «Продолжить курс» на текущий урок и счётчик завершённых этапов.
- Не встраивай базу или её представления на главную: служебные кнопки отвлекают ученика от урока.
- В свёрнутом блоке «Вернуться к уроку» показывай только уже пройденные страницы. При установке список пуст.
- После зачёта Codex переносит ссылку завершённого урока в список возврата, обновляет ссылку на следующий урок и счётчик.
- Все будущие этапы остаются в структуре курса, но не появляются на главной как варианты выбора.

## Проверка и синхронизация урока

1. Прочитай запись этапа по стабильному ID, соответствующий раздел PLAN.md и артефакты проекта.
2. Проверь каждый обязательный критерий. Чекбокс можно отметить только при наличии доказательства; не принимай ручную отметку ученика за доказательство.
3. Если нужна доработка, оставь этот этап текущим, поставь «Нужна доработка», запиши одно исправление и отметь только подтверждённые критерии.
4. Если решение зависит от уточнения ученика, оставь этап текущим и поставь «Нужно решение» с одним вопросом.
5. Если все критерии и объяснение ученика подтверждены, в одной последовательности обнови чекбоксы урока, текущую запись базы («Пройдено», доказательство, заметка наставника), следующую запись («В процессе») и главную страницу (счётчик, ссылку следующего урока и свёрнутый список завершённых уроков).
6. Повторно прочитай затронутые записи и главную страницу. Сообщай о переходе только после подтверждения изменений. Если часть записи не обновилась, перечитай текущее состояние и заверши ту же операцию без создания новых строк или страниц.

Первый этап с любым статусом кроме «Пройдено» остаётся текущим. «Готово к проверке», «Нужна доработка» и «Нужно решение» не открывают следующий урок.

## Временная недоступность

При временном сбое Notion заверши только текущий учебный цикл. Codex может удержать результат в контексте текущей сессии, но не создаёт локальную ведомость. После восстановления соединения синхронизируй результат в ту же запись.
